尼康云创资料库

双击同一层的 open-library.cmd，即可在浏览器使用。资料与照片都在本机，无需登录或联网。

添加照片与持续更新

  1. 把新照片复制到 photos 文件夹，可以按日期或拍摄主题建立子文件夹。
  2. 资料库打开后每 8 秒检查一次变化，新照片会自动出现。也可以点击页面上的 更新照片库，或双击最外层的 update-photos.cmd。
  3. 打开 我的实拍 查看照片。能够读出优化校准名称时，会按名称关联云创方案。首次导入需要读取文件并生成预览，数量多时请稍等。

JPG＋NEF 会尽量识别为同一次拍摄；重复复制相同文件不会增加拍摄张数。更新会跳过未变化的文件，不会修改原照片。正在复制的文件会留到后续检查。

新照片直接放入 photos 即可；原有示例保留在 photos/examples。原始照片文件名保持原样。

收藏方案与喜欢的照片

  • 在方案卡片上点击 收藏方案，勾选 只看收藏方案 可以快速找回。
  • 点击 我的实拍，在照片卡片上点 喜欢，再勾选 只看喜欢的照片。
  • 点开云创方案，里面的 我的实拍 展示使用该方案拍摄的照片。
  • 点开自己的照片，可以反查所用方案并打开 JPG 或 NEF 原文件。

收藏方案和喜欢照片分别记录。喜欢一张照片不会自动收藏某个方案。

自动识别与手动关联

目前已验证这台 Z50II 写入的优化校准格式。按机内名称与公开目录唯一匹配时自动关联；名称被截短、有多个候选、元数据缺失或同组记录不一致时，不会猜测。

在照片详情里的 关联方案 下拉框可以手动选择方案，后续更新会保留。选择 按相机记录自动识别 可以恢复自动关联；也可以选择暂不关联。

AUTO 表示相机记录为自动优化校准，不会自动指向具体云创。名称匹配也不保证所有参数与官网完全一致。

保存和备份

收藏与手动关联保存在 local/personal-records.json，关闭网页、重启或增加照片后仍然保留。程序还会保存上一份记录作为备份。

页面上可以 导出收藏与关联备份，得到 JSON 文件；换电脑或恢复记录时，用 导入记录备份 合并。程序不会清空现有收藏。

移动整个资料库时，请保留这个文件夹的完整结构。原照片从「photos」移走后会从当前列表消失，但收藏和关联记录会保留；同一拍摄重新放回时可继续使用。

文件夹说明

最外层入口用途

运行需要 Python 3.11 或更新版本、Pillow 和 tifffile。当前电脑已配置好。新电脑先按 README.md 安装并下载官方目录；日常浏览不依赖外部网络。

Git 只管理程序和文档。photos、local、下载的官方目录、生成的浏览页面和 recipes.xlsx 均不提交到 GitHub。迁移个人照片和收藏时，请另行复制 photos 与 local。

浏览与快捷操作

界面采用接近尼康云创官网的黑白灰配色，以黄色标记主要操作与选中状态。顶部的「资料与备份」菜单包含总表与个人记录的导入导出。

  • 舒展／紧凑：调整图片布局，选择会在本浏览器中保留。
  • 当前筛选会显示成可移除的标签，点击标签上的 × 即可单独取消。
  • 在详情中按 ←／→ 连续浏览，顺序遵循当前筛选；从某个方案进入「我的实拍」时，只浏览该方案下的照片。
  • 按 F 或点击详情里的大图切换专注看图，底部缩略图可直接跳转；再次按 F 回到资料阅读区。
  • Esc 关闭当前窗口，回到之前的位置；/ 聚焦搜索，? 打开快捷操作提示。输入文字时不会触发看图快捷键。

无法打开时

请再次双击 open-library.cmd。如果提示端口被其他程序占用，可以在「local/runtime.json」调整端口后重启本地服务；没有该文件时可从「app/runtime.example.json」复制。个人记录不受影响。启动错误会写入「local/runtime.log」。

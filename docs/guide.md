# 尼康云创资料库

双击同一层的 **open-library.cmd**，即可在浏览器使用。资料与照片都在本机。下载完成后的日常浏览无需登录或联网；官方同步需要联网。

## 网页手动同步云创

点击顶部的 **同步云创**，执行日常增量同步：读取官方目录，只下载新增或目录信息有变化的方案，更新相关介绍、参数、样片和作者资料。页面显示进度，以及完成后的新增、更新数量。打开网页、刷新页面和重启服务不会自动联系官方，也不增加任何官方同步定时任务。

打开或刷新页面不会显示上次同步的结果，只有本次点击 **同步云创** 后才显示进度和结果。已有且目录信息未变化的方案和头像直接复用，不逐个请求详情或核对图片；本地素材缺失或损坏时会补齐。目录没有变化时只读取方案目录与作者目录两次，随后提示 **目录没有变化，已复用本地方案**，不重新生成整份资料库。旧方案仅在详情内修改参数或替换同地址样片，日常同步不会发现；页面不提供完整核对入口。

更新先下载到独立目录，验证通过后整体切换。失败时保留原目录并显示原因；重启时会恢复被中断的文件事务。同步不会覆盖 photos、收藏、喜欢、手动关联或个人记录。已从官方列表消失的旧方案保留，避免原来的关联失效。

方案卡片的 **新增** 标记和 **本次同步新增** 筛选表示最近一次实际更新增加的方案，下次实际更新时重置；没有变化的检查和失败不会清除。排序支持 **最新发布**、**新增优先** 和 **官网顺序**。Excel 总表仍是原有静态导出，不随网页同步重写。

## 将本地内容同步到 GitHub 网页

本地页面顶部的 **同步到 GitHub 网页** 会把电脑里已有的云创方案、我的实拍、收藏状态和照片关联一起发布到公开网页。页面显示进度，完成后会出现 **打开网页**，不需要额外打开程序。

- 只新增或修完实拍照片：直接点击 **同步到 GitHub 网页**。
- 想获取新的官方方案：先点击 **同步云创**，等完成后再点击 **同步到 GitHub 网页**。

实拍只发布最长边 480 像素的缩略图与 1280 像素的压缩展示图，原始 JPG 保留在电脑里。网页只读，收藏、喜欢和关联统一在本地修改。刷新页面可以继续查看发布进度；重复点击不会启动第二次发布。打开本地资料库或自动扫描照片不会自行上传。

未变化的实拍会复用已有展示图，只为新增或修改的照片重新生成图片。每次仍检查图片尺寸、内容哈希和发布文件范围，但不会在电脑上重复跑整套程序测试。程序先比对上次成功发布的本地内容；照片、收藏、关联、云创资料和部署代码都没变化时，只确认线上版本，跳过扫描、导出、构建和上传，提示 **网页已经是最新，无需重复发布**。首次建立发布缓存仍需完整检查。有更新时，仍需等待 GitHub 构建和发布完成。

## 添加照片与持续更新

1. 把新照片复制到 **photos** 文件夹，可以按日期或拍摄主题建立子文件夹。
2. 资料库打开后每 8 秒检查一次变化，新照片会自动出现。也可以点击页面上的 **更新照片库**，或双击最外层的 **update-photos.cmd**。
3. 打开 **我的实拍** 查看照片。能够读出优化校准名称时，会按名称关联云创方案。首次导入需要读取文件并生成预览，数量多时请稍等。

JPG＋NEF 会尽量识别为同一次拍摄；重复复制相同文件不会增加拍摄张数。更新会跳过未变化的文件，不会修改原照片。正在复制的文件会留到后续检查。

新照片直接放入 **photos** 即可；原有示例保留在 **photos/examples**。原始照片文件名保持原样。

## 收藏方案与喜欢的照片

- 在方案卡片上点击 **收藏方案**，勾选 **只看收藏方案** 可以快速找回。
- 点击 **我的实拍**，在照片卡片上点 **喜欢**，再勾选 **只看喜欢的照片**。
- 点开云创方案，里面的 **我的实拍** 展示使用该方案拍摄的照片。
- 点开自己的照片，可以反查所用方案并打开 JPG 或 NEF 原文件。

收藏方案和喜欢照片分别记录。喜欢一张照片不会自动收藏某个方案。

## 自动识别与手动关联

目前已验证这台 Z50II 写入的优化校准格式。按机内名称与公开目录唯一匹配时自动关联；名称被截短、有多个候选、元数据缺失或同组记录不一致时，不会猜测。

能自动匹配的照片会直接关联方案。不能自动匹配时，照片详情会展开 **手动关联方案**，从下拉列表选择即可；方案较多时，可先用上方 **搜索方案** 按名称或作者缩小列表。输入搜索词不会保存，选中方案才会保存关联。已关联照片的手动选项默认收起，需要时点击 **手动修改关联**。后续扫描和官方同步会保留手动关联；在列表中选择 **自动匹配** 或 **恢复自动识别** 可以取消手动覆盖，也可以选择暂不关联。

## 照片解析提示

照片关联状态统一显示在卡片右下角。未提供或未识别出优化校准、未能匹配云创方案时，状态文字标黄；相机明确记录为 AUTO 时，显示普通颜色的“自动优化校准”，不视为异常。已手动关联或选择暂不关联的照片正常显示。文件损坏、权限不足等读取问题可在照片详情中查看。

正在复制或空文件会等下次扫描再解析。NEF 缺少内嵌预览时，可补充同组 JPG；无法读取的优化校准版本会显示版本号，不会猜测所用方案。程序不会修改原文件。

`AUTO` 表示相机记录为自动优化校准，不会自动指向具体云创。名称匹配也不保证所有参数与官网完全一致。

## 保存和备份

收藏与手动关联保存在 **local/personal-records.json**，关闭网页、重启或增加照片后仍然保留。程序还会保存上一份记录作为备份。

页面上可以 **导出收藏与关联备份**，得到 JSON 文件；换电脑或恢复记录时，用 **导入记录备份** 合并。程序不会清空现有收藏。

移动整个资料库时，请保留这个文件夹的完整结构。原照片从「photos」移走后会从当前列表消失，但收藏和关联记录会保留；同一拍摄重新放回时可继续使用。

## 文件夹说明

| 最外层入口 | 用途 |
|---|---|
| open-library.cmd | 日常浏览、收藏、反查和管理实拍 |
| photos | 放入新照片，可自由建立子文件夹 |
| update-photos.cmd | 立即检查新增、移动或移除的照片 |
| recipes.xlsx | 直接用 Excel 查看公开方案总表 |
| guide.html | 本说明，双击即可阅读 |
| README.md | 项目介绍与安装说明 |
| app | 程序与界面文件 |
| data/catalog | 官方方案、样片与作者头像 |
| local | 个人记录、照片索引、缩略图、配置及历史检查 |

运行需要 Python 3.11 或更新版本、Pillow 和 tifffile。当前电脑已配置好。新电脑先按 README.md 安装并下载官方目录；日常浏览不依赖外部网络。

主分支管理程序和文档，部署分支另外保存公开方案与经过压缩的实拍展示副本。原始 photos、local、完整个人记录、下载的原始官方目录、生成的浏览页面和 recipes.xlsx 均不提交到 GitHub。迁移个人照片和收藏时，请另行复制 photos 与 local。

## 浏览与快捷操作

界面采用接近尼康云创官网的黑白灰配色，以黄色标记主要操作与选中状态。顶部的「资料与备份」菜单包含总表与个人记录的导入导出。

- **舒展／紧凑**：调整图片布局，选择会在本浏览器中保留。
- 当前筛选会显示成可移除的标签，点击标签上的 × 即可单独取消。
- 在详情中按 **←／→** 连续浏览，顺序遵循当前筛选；从某个方案进入「我的实拍」时，只浏览该方案下的照片。
- 按 **F** 或点击详情里的大图切换专注看图，底部缩略图可直接跳转；再次按 F 回到资料阅读区。
- **Esc** 关闭当前窗口，回到之前的位置；**/** 聚焦搜索，**?** 打开快捷操作提示。输入文字时不会触发看图快捷键。

## 无法打开时

请再次双击 **open-library.cmd**。如果提示端口被其他程序占用，可以在「local/runtime.json」调整端口后重启本地服务；没有该文件时可从「app/runtime.example.json」复制。个人记录不受影响。启动错误会写入「local/runtime.log」。

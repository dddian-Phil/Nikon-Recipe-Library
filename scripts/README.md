# 启动脚本

在对应系统的文件夹中双击脚本。脚本可从其他工作目录调用，路径支持空格和中文。

| 路径 | 用途 |
|---|---|
| `macos/open-library.command` | 打开资料库 |
| `macos/setup-mac.command` | 首次安装或更新依赖 |
| `macos/stop-library.command` | 停止后台服务 |
| `macos/sync-website.command` | 同步公开网页 |
| `macos/update-photos.command` | 更新照片索引 |
| `windows/open-library.cmd` | 打开资料库 |
| `windows/restore-v1.cmd` | 恢复 v1 |
| `windows/sync-website.cmd` | 同步公开网页 |
| `windows/update-photos.cmd` | 更新照片索引 |

使用方式见项目根目录 README.md；网页同步和版本恢复的详细说明在 docs/。

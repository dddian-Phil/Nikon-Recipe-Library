尼康云创 · 网页版使用说明

使用 iPhone Safari 打开网址即可浏览，不需要让电脑保持开机。也可以通过 Safari 的分享菜单将页面添加到主屏幕。

浏览与样片

  • 按方案名称、作者、器材或介绍关键词搜索；点击搜索框旁的「筛选」，可按作者头像、相机、镜头或基础优化校准筛选。
  • 支持最新发布、新增优先和官网顺序；「本次同步新增」指发布快照记录的最近一次本地实际更新；没有变化的目录检查不会清除新增标记。
  • 点击卡片查看公开参数与官方样片。详情中的左右按钮连续浏览，点击大图切换专注模式。
  • 「打开官网样片」打开本站保存的官方展示图。在 iPhone 上可以长按图片使用 Safari 提供的保存或分享操作。
  • 详情提供公开参数 JSON；顶部菜单提供配方总表 CSV，可在表格软件中打开。
  • 切换到「我的实拍」浏览维护者发布的照片，或用「有我的实拍」筛选有拍摄实例的方案。方案详情下也可以直接打开对应实拍。
  • 实拍支持器材筛选、搜索、左右连续浏览、专注看图与缩略图导航。点击「查看这个云创方案」可以返回对应方案。
  • 「只看收藏方案」「只看喜欢的照片」展示维护者在本地保存并发布的选择；浏览者不能修改收藏或照片关联。

网页内容怎样更新

每次更新会一起发布电脑里已有的云创方案、我的实拍、收藏状态和照片关联。实拍只上传压缩展示图，原始 JPG 保留在电脑里。

  • 本地「同步云创」：平时只读取方案目录，已有方案、图片和作者资料直接复用；发现新增、方案变更或本地作者资料缺失时才补读作者目录。
  • 本地「同步到 GitHub 网页」：把电脑里的方案和实拍一起更新到这个网页，页面会显示进度和完成结果。

只新增或修完实拍照片时，点「同步到 GitHub 网页」就够了。需要更新官方方案时，先点「同步云创」，完成后再点「同步到 GitHub 网页」。不用另外打开程序。

未变化的实拍会复用已有展示图；本地和网页都没有变化时，只快速确认版本，不重复导出、构建或上传，直接提示已经是最新。有更新时，页面会显示上传与发布进度，等待网页真正更新后再提示完成。

本页显示最近一次发布的内容；打开或刷新这个网页不会自动下载新方案或读取电脑照片。

本地完整版

添加照片、修改关联、收藏、喜欢和记录备份在本地完整版完成。网页版只读，展示最近一次发布的状态，不自动回传修改，也不能扫描电脑文件或打开本地原图。

实拍列表、详情与专注看图共用最长边 1280 像素的压缩展示图，已加载的图片可复用浏览器缓存。原始 JPG 不上传，展示图不携带 EXIF、GPS、相机序列号或内嵌原图；拍摄参数来自单独整理的公开字段。可见的展示图仍可以被保存或截图。

网页版提供由当前快照生成的 CSV。本地 Excel 是独立导出，官方同步本就不会自动重建它；为避免发布未经检查的本机文件，本站不复制本地 Excel。

数据范围

内容来自 Nikon 中国站公开色彩灵感库，保留作者与官方来源链接。官方样片是公开展示图，并非 RAW 原片；相机与镜头表示样片拍摄器材，不代表方案兼容性限制。自定义曲线只保留官方公开标记，不补造曲线数值。本项目与尼康官方无隶属关系。
